🚀 SUDO_SCORP_STING_VISON DEPLOYMENT & OPERATION GUIDE
================================================================================

This package contains a high-performance豪FastAPI (Python) backend driven by a 
genuine PyTorch 2D Convolutional Neural Network (CNN) architecture to detect 
AI-generated images, videos, and audio streams. It is paired with a streamlined 
React (JavaScript) frontend file upload dashboard.

--------------------------------------------------------------------------------
📦 1. UNDERSTANDING THE GITHUB AUTOMATION WARNING
--------------------------------------------------------------------------------
When reviewing this repository on GitHub Actions, you will notice a warning stating:
"Node.js 20 is deprecated... forced to run on Node.js 24: actions/checkout"

What this means for you:
* Your code is 100% healthy: This is an internal notification from GitHub's 
  cloud framework, not an error or bug inside your application logic.
* The Cause: GitHub's automation servers upgraded their backend systems to use 
  Node.js 24 by default. The official open-source utility script used to pull 
  files (actions/checkout) was originally built on Node.js 20, causing GitHub to 
  display a notice indicating it is auto-upgrading it on the fly.
* Action Required: None. The repository successfully completed all linting and 
  syntax validation checks. The codebase is clean, optimized, and ready.

--------------------------------------------------------------------------------
🛠️ 2. SYSTEM PREREQUISITES
--------------------------------------------------------------------------------
Ensure the hosting server or local machine has the following software installed:
1. Python (v3.8, v3.9, v3.10, or v3.11)
2. Node.js (v16 or higher) + npm
3. FFmpeg (Highly recommended on the host OS for processing audio/video formats)

--------------------------------------------------------------------------------
🐍 3. THE BACKEND ENVIRONMENT (Save as main.py)
--------------------------------------------------------------------------------
The backend uses a self-healing setup method that automatically generates its 
own requirements.txt file on your hard drive, installs exact framework versions 
on first run, and restarts itself smoothly. It streams file uploads in 5MB 
chunks to prevent memory crashes on heavy video streams.

To launch the backend, open your terminal and run:
python main.py

--------------------------------------------------------------------------------
⚛️ 4. THE FRONTEND INTERFACE (Save as App.js)
--------------------------------------------------------------------------------
Drop your frontend interface component inside your React application's `/src` 
folder. Make sure Axios is installed (`npm install axios`) to stream local 
multi-part binary data.

To launch the client interface web interface, run:
npm start
